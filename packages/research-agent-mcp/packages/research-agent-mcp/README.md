# @research-agent-mcp

Minimal MCP runtime for research agent notebooks (~600 LOC target).

## Quick Start

\`\`\`bash
npm install
npm run build
AGENT_ID=agent-1 NOTEBOOK_PATH=./examples/research-agent-example.src.md npm start
\`\`\`
